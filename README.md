# Simulador de Recursividad

Simulador interactivo para ver, paso a paso, cómo funciona la recursividad con **Factorial** y **Fibonacci**: pila de llamadas, árbol de recursión y código con la línea en ejecución resaltada.

## Probarlo

- **Sin instalar nada:** abre `preview.html` en el navegador (carga React, Tailwind y Lucide desde CDN).
- **En un proyecto React con Tailwind:** copia `RecursionSimulator.jsx` y ejecuta `npm install lucide-react`.

## Atajos

`←` / `→` pasos · `Espacio` reproducir/pausar · `R` reiniciar
